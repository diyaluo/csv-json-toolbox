Frequently Asked Questions

Does my data get uploaded anywhere?

No. The toolbox runs entirely on your local computer as a command-line utility with no network calls, so sensitive CSV and JSON data never leaves your machine.

Can it handle the BOM added by Excel CSV exports?

Yes. It detects and handles the UTF-8 byte-order mark that Excel adds, so the first column name is read correctly instead of carrying hidden characters.

How does splitting keep headers intact?

When you split a CSV by row count, every output shard automatically repeats the original header row, so each chunk opens and imports correctly on its own.

What does validation actually check?

It verifies that every CSV row has the expected number of columns and that JSON/JSONL content is legal, then reports the specific lines that fail instead of failing silently at import time.

Do I need Python packages or an API key?

No external dependencies and no API key. It runs with a local runtime and a single command, file in and file out.
